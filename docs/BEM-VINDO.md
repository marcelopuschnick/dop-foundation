### ✅ Por Que Este Projeto?

A **DOP Foundation** nasceu do desejo de devolver aos artistas:

- 🎼 **Controle** — Dono do master, define o preço
- 💎 **Transparência** — Blockchain auditável por qualquer um
- ⚡ **Agilidade** — Splits automáticos em tempo real
- 🔒 **Privacidade** — Dados no seu dispositivo

## 🛠️ Ambiente de Desenvolvimento

### Configuração do Projeto

```bash
# 1. Clonar
git clone https://github.com/SEU_USUARIO/dop-foundation.git
cd dop-foundation

# 2. Ativar venv
python -m venv .venv
.venv\Scripts\Activate.ps1  # Windows
source .venv/bin/activate   # Linux/Mac

# 3. Instalar
pip install -r requirements.txt
```

### Testes Rápidos

```bash
# Verificar instalação
python --version     # ✅ Python 3.10+
streamlit version    # ✅ Streamlit instalado
ganache              # Ganache instalado?

# Rodar dashboard para testar UI
streamlit run dashboard/app.py

# Ver contrato na blockchain local
python scripts/ciclo_amoy.py
```
